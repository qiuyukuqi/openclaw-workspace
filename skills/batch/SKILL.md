# /batch — 并行批量任务技能

将大任务分解为多个独立单元，spawn多个子agent并行处理，最后汇总结果。

## 使用场景
- 批量处理文件（批量修改、格式化、重命名）
- 批量搜索/分析
- 需要并行执行多个独立子任务的场景

## 执行流程

### Phase 1: 规划
1. 分析任务，确定可并行的子任务
2. 每个子任务必须独立（无依赖关系）
3. 子任务数量建议5-15个（太多会浪费资源）

### Phase 2: 执行
```
sessions_spawn 多个子agent，每个处理一个子任务
使用 streamTo: "parent" 或直接等完成
```

### Phase 3: 汇总
1. 收集所有子agent的结果
2. 合并冲突（如有）
3. 产出统一报告

## 注意事项
- 子任务之间必须有明确的数据边界
- 文件操作避免多个子agent写同一文件
- 每个子agent的task描述要清晰完整（它没有主会话上下文）

## 示例
用户: "把skills/下所有SKILL.md的格式统一"
→ Phase 1: 列出所有SKILL.md文件
→ Phase 2: 每3-5个文件spawn一个子agent进行格式化
→ Phase 3: 汇总修改结果
